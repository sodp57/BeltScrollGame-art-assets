# 개발 세션 요청 — 돌진 베기(smash) 날리기 + 적 무게 등급 (아트 세션, 2026-10-19)

사용자 요청(원문 요지): "주인공의 돌진베기에 날리기 효과 — 맞은 적이 날아가게. 적 속성에 소형·중형·대형에 따라 가벼움·무거움을
설정할 것, 소형은 더 멀리 날아간다. 쉐도우 오브 미스타라 파이터 돌진 베기처럼 한번에 촤악 시원하고 빠르게 베어나가는 느낌,
타격감·참격감이 잘 느껴지게."

연출 시안 영상: 공개 저장소 `review_1019_smash/smash_blow_demo.mp4` (아트 세션이 합성으로 만든 목표 느낌 — 수치의 기준).
아래 수치는 시안 영상에 쓴 값이다. 단위 "px"는 원본 px(화면 3배 전), 시간은 초.

## 1. 새 적 스탯 — 무게 등급
- `CharacterStats.weight_class`: `SMALL` / `MEDIUM`(기본) / `LARGE` (보스는 기존처럼 안 날아감).
- 모든 넉백(일반 타격 포함)에 무게 배율을 곱한다. 날아가는 거리·높이 배율:

| 등급 | 넉백 속도 | 뜨는 높이 | 시안 영상 날아간 거리 | 예 |
|---|---|---|---|---|
| SMALL (가벼움) | ×1.5 | ×1.3 | 약 190 px | 고블린·도적 졸개 |
| MEDIUM | ×1.0 | ×1.0 | 약 125 px | 산적(적 1호) |
| LARGE (무거움) | ×0.55 | ×0.45 | 약 60 px, 거의 안 뜸 | 오우거·중갑병 |

- 히트스톱 중 맞은 쪽 흔들림 폭도 LARGE는 절반(무거운 손맛), SMALL은 그대로.

## 2. 플레이어 Smash 상태 (커맨드 ↓↘→ + 공격)
- 애니메이션 `smash_se` (아트 durations 갱신: 20fps 단위 **[1, 0.75, 2, 0.5, 0.5, 0.5, 0.75, 1, 2.5, 1.5, 1.5]** = 0.625 s).
  궤적 `gs_smash_se`는 몸 동기형(같은 프레임·같은 시간, 이펙트 세션이 같은 값으로 갱신 중).
- **이동(핵심 — "베어나가는" 느낌):** f02(몸을 낮춘 돌진 자세)부터 f06까지 앞으로 빠르게 미끄러진다.
  시안: f02 동안 가속, f03~f06 최고 속도 약 **600 px/s**, f07부터 급감속(f08 정지 자세 유지). 총 이동 약 100 px.
  적과 겹쳐도 멈추지 않고 **관통**한다(판정 동안 플레이어-적 몸 충돌 무시).
- **판정:** f05~f06, 같은 줄의 적 전부 1회씩(관통 다단 아님, 적마다 1회).
- **맞은 순간:**
  1. 히트스톱 **0.10 s** — 플레이어·적·궤적 이펙트 전부 멈춤(기존 히트스톱 규약).
  2. 화면 흔들림 0.12 s, 진폭 3 px(가로 위주).
  3. 적 흰 번쩍임 2프레임(기존 flash).
  4. 적 몸 중심(발 위 ~40)에 `hit_slash_l` + 새 `smash_cut`(이펙트 세션 제작 중 — 적 몸을 가로지르는 긴 수평 참격).
  5. 히트스톱이 풀리는 순간 날리기: 넉백 기본 **420**(무게 배율 적용, blow_speed_threshold 180보다 커서 벽 튕김·적끼리 충돌 그대로 동작),
     뜨는 높이 = 몸 높이 × 0.35 × 무게 높이 배율. 적 애니메이션 `hurt2`(f00 충격 → **f01 공중 유지** → f02 착지 엉덩방아 → f03 누움).
     날아가는 동안 `blow_trail`(기존), 착지 `dust_knock`, 튕기면 `bounce_dust`.
- **잔상:** f02~f07 동안 0.05 s마다 몸 잔상 1장, 최대 3장, 알파 0.5 → 0, 옅은 파란 틴트(필살기 계획서의 잔상과 같은 도구로 공용화 권장).
- 시작 시 발밑 `dust_dash` 1회(이펙트 세션 권고, 10/17).

## 3. 참격 색 결정 (사용자 10/19)
`smash_cut`은 **회색**(무속성 규칙). `smash_cut_gold`는 쓰지 않는다.

## 4. 산적 근접 공격 사거리 — 그림에 맞추기 (사용자 10/19: "칼이 닿지 않았는데 피격되는 걸로 보인다")
원본 px 실측(192x160 프레임, 발 (96,148), 동쪽 기준). 게임 값은 이 수치 × 스프라이트 배율(3)로 환산:
- 타격 프레임 `attack` f06(시작 후 12fps 단위 1+1+1+1.5+2+0.5 = 7 → **0.583 s**)에서 시미터 칼끝 = **발 앞 32 px**, 칼날 구간 발 앞 약 18~32 px, 높이 발 위 약 25~45 px.
- 주인공 몸 앞면 = 발 앞 약 17 px(대검 제외).
- → 닿는 거리: **발 사이 ≤ 약 45 px**(칼끝이 몸에 3~4 px 박히는 정도). 지금 `enemy_stats.tres attack_range = 45`가 월드 단위라면 원본 px로는 15이므로
  배율을 확인해 **attack_range ≈ 45 원본 px 상당(×배율)**, 히트박스 중심 = 발 앞 약 25 px, 폭 ±8 px로 맞춰 주세요(멀리서 맞는 판정 제거).
- 판정 생성 시점은 f06 시작(0.583 s)에 맞추고, 그 전(f00~f05 예비동작)에는 판정 없음.
- 시안 영상 `review_1019_smash/bandit_reach_fix.mp4`: 발 사이 42 px에서 칼끝이 몸에 닿는 순간 피격.
