## 쓰는 순서
1. 아래 표에서 작업 파일을 엽니다.
2. **가장 성능 좋은 모델**을 고른 새 대화를 엽니다. 작업 하나에 대화 하나를 쓰고, 수정 요청도 같은 대화에서 해야 화풍과 설정이 유지됩니다.
3. 파일 안의 `복사할 프롬프트` 칸을 통째로 붙여 넣습니다. `첨부` 줄에 적힌 그림이 있으면 같이 올립니다(`refs/` 폴더).
4. 결과를 돌려주는 방법:
   - 그림: 이 대화창(Claude)에 그대로 첨부
   - 음원: `C:\GameDev\inbox\gemini\bgm\` 에 `번호_이름.mp3`(또는 wav)로 저장한 뒤 알려 주기
   - 긴 글: Claude 대화창에 붙여 넣기. 너무 길면 `C:\GameDev\inbox\gemini\story\` 에 txt로 저장
5. 아트 세션이 가공·적용하고 게임 캡처로 보여드립니다.
